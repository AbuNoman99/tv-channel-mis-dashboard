# TV Channel MIS & Advertisement Revenue Dashboard

**Excel-Based MIS & Business Reporting Portfolio Project**

## Project Overview
This guided portfolio project demonstrates how Microsoft Excel can be used to organize, analyze and report television advertising revenue, collections, outstanding payments and operating expenses.

The project uses a realistic simulated dataset designed for practical MIS, reporting and data analysis training.

## Dataset
- 10,000 transaction records
- 6,500 advertisement bookings
- 3,500 expense records
- 90 fictional advertising clients
- 22 months of data (January 2025 - October 2026)
- Historical public advertising rate information used as a reference

## Tools & Skills
- Microsoft Excel
- SUMIF, SUMIFS, COUNTIFS, IF and IFERROR
- INDEX, MATCH and XLOOKUP
- Data Cleaning and Data Validation
- PivotTable Practice
- KPI Reporting and Data Visualization
- Dashboard Analysis
- Financial Reconciliation

## Project Workflow
1. Organize client, advertisement and expense records.
2. Calculate gross and net advertising revenue.
3. Calculate collected and outstanding amounts.
4. Summarize monthly financial performance.
5. Analyze revenue by client, business sector and advertising slot.
6. Analyze operating expenses by department.
7. Present KPIs and charts in an Excel dashboard.
8. Validate financial totals using reconciliation checks.

## Dashboard Features
- Monthly Revenue and Expense Overview
- Net Revenue and Outstanding Payments
- Collection Rate
- Advertising Performance
- Sector-wise Revenue Analysis
- Department-wise Expense Analysis
- Advertising Slot Performance
- Four Business Charts

## Workbook Structure
The Excel workbook contains 18 worksheets, covering raw data, client information, reference rates, monthly reporting, analytical summaries, dashboard visualization, formula practice, PivotTable exercises and quality checks.

## Important Limitations
- Client identities and financial transactions are fictional and simulated.
- The workbook was developed as a guided practice project.
- Some report summaries are pre-calculated snapshots rather than fully dynamic calculations.
- PivotTable exercises are provided for hands-on practice.
- Financial results are educational examples, not actual television channel financial statements.

## Career Relevance
This project demonstrates practical understanding of Excel-based reporting workflows relevant to MIS Executive, Reporting Executive, Junior Data Analyst and Office Executive positions.
